# promting

## Make your own website

1. Click **Fork** at the top of this repository to create a copy in your GitHub account.
2. In your fork, open **Settings > Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then click **Save**.
3. Check in the Settings to ensure GitHub Pages is set up correctly. You should see a message indicating that your site is published at `https://YOUR-USERNAME.github.io/promting/webpage/`.
